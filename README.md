# Fieldnotes — Visual Learning Library

A small, offline-ready learning library PoC for WAEC revision.

## Run locally

Open `index.html` in a modern browser. No install or build step is needed.

## Deploy to Vercel

Create a Vercel project from this repository. The project is a static site; it needs no build command or environment variables.

## Contents

- Five subjects: Mathematics, Biology, Geography, History, and Civic Education
- Twenty illustrated visual guides and four practice question sets
- Search, subject and format filters, saved items, answer reveals, and fullscreen projection

Question sets contain original illustrative WASSCE-style practice material for the prototype, not verified official WAEC past-paper transcripts.
